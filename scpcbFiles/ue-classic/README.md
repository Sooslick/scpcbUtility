Room descriptions, mesh bounds, light counts, and forest heightmaps are derived from
**SCP – Containment Breach Ultimate Edition Classic v5.5.4.1**, by its contributors,
using the supplied CBUE-Classic source distribution (`Data/rooms.ini`, `GFX/map`,
and `Source Code/Map_System.bb`). The game is based on SCP: Containment Breach.

These data and assets retain the [Creative Commons Attribution-ShareAlike 4.0 license](https://creativecommons.org/licenses/by-sa/4.0/),
as stated in the game source README and this repository's LICENSE. The room table was
generated by `tools/export-ue-rooms.cjs`; it preserves INI ordering, which controls weighted room selection.
Bounds use the drawn mesh, matching `GetMeshExtents(GetChild(rt\obj, 2))` in UE.
